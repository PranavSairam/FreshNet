# Machine learning

`DualPathFreshNet` is a trainable PyTorch model with:

- a **spatial path** for local texture and structure
- a **color path** for global chromatic layout
- a fused linear classifier

The network is defined in `dual_path.py`. There are **no trained weights** in this repository.

## Dataset preparation

Use the preparation CLI before training. It maps labels, audits quality, finds duplicates, and writes leakage-aware manifests.

```powershell
$env:PYTHONPATH = "$pwd\ml"
python ml\prepare_dataset.py --config configs\dataset.yaml
```

Full details: [docs/DATASET.md](../docs/DATASET.md).

## Install (after Python 3.10+)

CPU (Windows PowerShell or macOS/Linux):

```powershell
python -m pip install -r ml/requirements.txt
```

If you have an NVIDIA GPU, use the install command generated by the official PyTorch selector instead of guessing a CUDA wheel:

https://pytorch.org/get-started/locally/

Current intended pairing from PyPI at scaffold time: `torch` 2.14.x with `torchvision` 0.29.x. Pin whatever pair `pip` actually installs on your machine.

## Train only on a real dataset

```powershell
python ml/train.py --data-dir data/raw/your-dataset --num-classes 3
```

`--num-classes` must match the number of class folders. Do not invent a Medium class for a two-class dataset.

## Outputs

Predictions are **visual freshness estimates**. An image cannot establish whether food is safe to eat. Do not convert class probability into a freshness score or remaining shelf life.
